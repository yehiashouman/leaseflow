# List API

Paths use the `/api/v1` prefix. Lists and totals use the same authenticated role and record scope. Send `page` as an integer from 1 through 10,000. Each page contains up to 20 rows and returns `{ items, total, page, pageSize }`. A page beyond the last returns an empty `items` array. Each order breaks ties by ID. Repeat the same filters and sort across pages. Concurrent edits can move rows between pages.

Inventory, contract, and request lists retain array responses when `page` is omitted. Other lists in the table default to page 1. `q` accepts at most 150 characters and searches the listed fields by substring.

| Path                        | Filters besides `page`                                                                                                                                                               | Sort order                                                                                      |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| `/inventory/landlords`      | `status` `ACTIVE` (default), `ARCHIVED`, `ALL`. `q` searches name, company, and email.                                                                                               | `sort=NAME` (default) by name ascending, or `NEWEST` by creation time descending. ID ascending. |
| `/inventory/units`          | `status` `CURRENT` (default), `ARCHIVED`, `ALL`. `q` searches name, area, and building.                                                                                              | `sort=NEWEST` (default) by creation time descending, or `NAME` by name ascending. ID ascending. |
| `/contracts`                | `status` matches a contract status. `q` searches tenant, space, and unit names.                                                                                                      | `sort=NEWEST` (default) or `OLDEST` by start date. ID descending.                               |
| `/contracts/:id/records`    | Required `section` `payments`, `deposits`, or `requests`.                                                                                                                            | Payment due date or creation time descending, then ID descending.                               |
| `/requests`                 | `status` and `type` match request status and type. `q` searches title.                                                                                                               | `sort=RECENT` (default) or `OLDEST` by update time. ID descending.                              |
| `/reviews`                  | `status` `ALL` (default), `OPEN`, `REVIEWED`, `DEFERRED`. `q` searches tenant, space, and unit names.                                                                                | `sort=NEWEST` (default) or `OLDEST` by due date. ID descending.                                 |
| `/expenses`                 | `category`, `currency` `AED` or `USD`, `status` `ACTIVE` (default), `VOID`, `ALL`, inclusive UTC calendar dates `from` and `to` (`YYYY-MM-DD`). `q` searches vendor and description. | `sort=NEWEST` (default) or `OLDEST` by expense date, then ID descending.                        |
| `/payments/:id/receipts`    | No additional filters.                                                                                                                                                               | Creation time descending, then ID descending.                                                   |
| `/documents`                | `purpose`, `targetId`, and `seriesId`.                                                                                                                                               | Creation time descending, then ID descending.                                                   |
| `/tenants`                  | `status` matches an account status. `q` searches tenant name and email.                                                                                                              | `sort=NAME_ASC` (default) or `NAME_DESC` by name. ID ascending.                                 |
| `/invitations`              | `status` `PENDING`, `ACCEPTED`, `REVOKED`, or `EXPIRED`.                                                                                                                             | Creation time descending, then ID descending.                                                   |
| `/notifications`            | `status` `ALL` (default), `UNREAD`, or `READ`.                                                                                                                                       | Creation time descending, then ID descending.                                                   |
| `/notifications/deliveries` | `state` matches a delivery state.                                                                                                                                                    | Creation time descending, then ID descending.                                                   |
| `/reports`                  | Required `requestId`.                                                                                                                                                                | Creation time descending, then ID descending.                                                   |
| `/admin/managers`           | `status` matches an account status. `q` searches name and email.                                                                                                                     | Creation time descending, then ID descending.                                                   |
| `/admin/request-categories` | No additional filters.                                                                                                                                                               | Request type, then name, then ID ascending.                                                     |
| `/admin/audit`              | `entityType` and `action`, up to 100 characters each.                                                                                                                                | Creation time descending, then ID descending.                                                   |
| `/operations/business-jobs` | `state` and `kind` match a business job state and kind.                                                                                                                              | Next run ascending, then ID ascending.                                                          |

`/expenses/export.csv` accepts the same expense filters and exports up to 1,000 rows in the same order. Contract and expense option lists return up to 500 records per option group.
